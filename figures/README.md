# Figures

```bash
python figures.py          # all figures
python figures.py 4a 4b    # selected figures
```

Keys: `2 3a 3b 4a 4b 5 S1 S2` (Figure 1 is `fig1.tex`). Needs `numpy` and `matplotlib`.

| file | role |
|---|---|
| `figure_data.py` | every value plotted, with the run it came from (generated by `make_table3.py` and `make_diverge.py`) |
| `figures.py` | one function per figure; writes PDFs next to itself |
| `fig1.tex` | The two panels of the correspondence figure as a TikZ fragment, `\input` by the manuscript |
| `additivity_summary.json` | input of `fig2`, produced by `summarize_additivity.py` |

| key | content |
|---|---|
| `S1` | order sensitivity, Geneformer vs scGPT |
| `2` | per-pathway regression slope and Pearson r against additivity |
| `3a` | matched-budget bars and k-scaling of the margin |
| `3b` | attack relative to greedy against budget |
| `4a` | interaction plot |
| `4b` | forest plot of simple effects and the interaction |
| `5` | acceptance-rule difference against budget; gradient ratio |
| `S2` | attainment of the k = 2 optimum |
